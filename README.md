# About The Story of Code

**The Story of Code — A Young Programmer's Journey** is an interactive, page-turning storybook designed to introduce young readers (ages 5–13) to the fundamentals of programming through JavaScript. It is structured as a journey in three parts:

- **Part One — Adventurers** (ages 5–8): Meeting the computer, basic values, variables, conditionals, loops, and functions.
- **Part Two — Explorers** (ages 9–11): Arrays, objects, higher-order functions, debugging, and the DOM.
- **Part Three — Masters** (ages 12–13): Classes, asynchronous programming, regular expressions, canvas drawing, and HTTP/fetch.

Each chapter combines a short story, key ideas, code examples, and hands-on exercises. The book runs entirely in the browser and uses keyboard and button navigation to turn pages.

## Origins

This little book was refactored from **Eloquent JavaScript** by Marijn Haverbeke, with deep gratitude for its clear thinking and generous spirit. The retelling adapts the material for a younger audience, adding illustrations, narrative framing, and a gentler learning curve. All mistakes in the retelling are the author's own.

## Technical Notes

- The book is built with plain HTML, CSS, and JavaScript — no frameworks or build tools required.
- Navigation works via on-screen buttons, arrow keys, Page Up/Down, Home/End, and the table of contents.
- A progress bar and page indicator help readers keep their place.
- The layout is responsive and respects `prefers-reduced-motion`.
- Without JavaScript, all pages stack vertically so the content remains fully readable.
